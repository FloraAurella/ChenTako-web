## 交互设计

- `/` 打开与输入容器对齐的浮层，列表采用图标、中文名称、同行说明；手机上说明换行，避免横向溢出。
- 模型 `/model`、思考强度 `/effort`、压缩历史 `/compact`、帮助 `/help` 共用原业务操作。
- 顶层与选项子级不显示额外标题和底部说明；帮助页保留正文标题，当前值使用右侧勾选。键盘说明可在 `/help` 查看。
- 中性色选中与悬停，说明使用满足对比度的现有文字令牌。输入框去除内部绿色焦点轮廓，其他输入框和按钮保留焦点反馈。
- 可选展示元数据由功能模块注册。指令文本仍不进入模型请求，输入法、附件、忙碌、会话切换和取消行为不变。

## 品牌资源

页面标题、首次启动、侧栏、设置、日志、下载名称改为 ai-chatbox。品牌 SVG 重绘为对话框与 AI 字样，24×24 单色圆角描线；唯一图形源为 `src/resources/logos/ai-chatbox.svg`。已持久化的 `paper-pen` 形状 ID 继续映射到新图形，避免旧主题失效。

## 兼容边界

“全部更名”落实为当前产品名称、资源和新公开入口更名，不破坏已经发布的数据协议。

| 新入口或输出 | 旧兼容处理 |
| --- | --- |
| `.ai-chatbox.zip` / `ai-chatbox-conversation` | 仍可导入旧 ZIP、JSON 会话与图片 |
| `ai-chatbox-theme-package`、`ai-chatbox-theme` | 读取旧品牌与更早主题格式 |
| `window["ai-chatbox"]` | 未提供时使用 `window.clawbox` |
| `AiChatboxThemeAPI`、`ai-chatbox:themechange` | 旧 API 与事件继续提供，两套 API 随 Scope 释放 |
| `AI_CHATBOX_*` | 优先新环境变量，旧 `CLAWBOX_*` / `TRIBBLEBOOK_*` 兜底 |
| `x-ai-chatbox-token` | 后端接受新旧认证头；旧桌面桥发旧头，以便连接旧服务 |
| health `service: ai-chatbox-server` | `ok: true` 健康状态契约不变 |

保留的旧字符串仅用于：旧浏览器持久化键、主题二进制容器与桌面文件名、历史工具事件、兼容入口与测试材料、历史验证记录、仓库外真实参考路径。不会移动用户文件或更改加密密钥派生。旧桌面实际路径由桥返回显示；新安装提示使用“本机应用数据目录”。Electron 主进程与仓库外服务没有修改。

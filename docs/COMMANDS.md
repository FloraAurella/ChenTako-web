# 指令系统第一版

在聊天输入框输入 `/` 即可查看可用指令。原有附件、发送／停止、模型与强度、上下文圆环按钮继续保留；指令是同一业务操作的键盘入口。

## 可用指令

| 指令 | 用途 | 示例 |
|---|---|---|
| `/model` | 打开模型列表；可按模型名或供应商名称搜索 | `/model model-a` |
| `/effort` | 选择思考强度，或恢复跟随项目／聊天配置 | `/effort high`、`/effort 高`、`/effort default` |
| `/compact` | 压缩当前会话已完成的历史，保留原聊天记录 | `/compact` |
| `/help` | 在输入区上方查看帮助，不创建聊天消息 | `/help` |

强度支持 `low`（轻量）、`medium`（中等）、`high`（高）、`xhigh`（极高）、`max`（最大），以及 `default`／“跟随配置”。供应商协议对强度的处理仍沿用原适配规则，不代表所有模型都原生支持全部档位。

`/model` 只展示启用供应商中的有效模型。唯一且精确的模型名可直接执行；同名模型必须选择供应商；部分匹配只展示结果，不自动切换。没有模型时可以查看帮助和打开空列表，然后到设置中配置。

## 输入规则

- 整条输入去掉首尾空白后，为以 `/` 开头的单行内容，才按指令处理。指令名大小写不敏感，模型名保持原样。
- 正文中的斜杠、代码块和多行内容仍按普通消息发送。
- 未知指令和非法参数不会发送给模型，输入保留并显示错误。
- 单行输入使用 `//` 发送字面量：输入 `//model`，模型收到 `/model`。多行内容不应用这一转换。
- 指令原文不进入模型请求、聊天标题和普通聊天历史。指令不会发送、删除或清空待发送附件。
- 配置指令成功后清除对应输入；失败和取消保留输入。异步完成不会清除后来输入的新草稿，也不会修改另一个会话的草稿。

## 补全与选择

输入 `/` 或前缀打开列表，也可以用中文用途搜索，例如 `/思考`。

- `↑`、`↓`：移动列表选择；帮助面板内用于滚动，也支持 Page Up / Page Down。
- `Tab`：补全指令或参数，不执行参数变更。
- `Enter`：在建议列表中补全；在参数列表中确认选择；完整快捷参数直接提交。
- `Esc`：关闭面板并返回输入框；点击面板外部关闭，不清除草稿。
- `Shift + Enter`：换行。中文输入法确认候选时不执行指令。

选择 `/compact` 建议只补全输入，需要再次按 Enter 才执行。也可以在完整指令输入后点击原有发送按钮提交；生成期间该按钮仍然是停止按钮，不执行指令。

帮助、补全位于输入区上方；执行反馈在聊天滚动区域末尾显示为与上下文压缩一致的图标文字标签，长文本自动换行，不再出现在输入框底部。成功反馈保留 6 秒，错误反馈保留 10 秒；继续输入或切换会话时清理，不保存到普通聊天历史。帮助和配置切换没有额外模型请求。`/compact` 会通过原 `/api/chat/compress` 接口发起额外模型请求。

## 配置作用范围与并发

模型和强度沿用原按钮的记忆规则：修改当前会话及现有最近选择记忆，不改变项目或全局默认配置。恢复跟随配置清除当前会话强度覆盖。

首次响应期间模型与强度指令不可用，正常结束、停止或失败后解锁。之后的回复或压缩期间仍可修改模型、强度；当前请求保持启动时的配置，修改用于后续请求。发送准备时固定供应商、模型、强度、配置、资料及辅助模型，正常响应结束后的自动压缩使用同一快照；发送前不再自动压缩。

正在回复、准备发送或压缩时不能执行 `/compact`，不会排队或自动停止当前任务。普通消息也没有新增排队能力。切换项目导致发送准备失效时，保留输入并要求重新发送。

## 开发结构

| 位置 | 职责 |
|---|---|
| `src/contracts/commands.ts` | CommandContribution、CommandContext、CommandOption 和 CommandResult 公共契约 |
| `src/modules/commands/domain/` | 区分普通消息、字面量和指令，解析名称与参数 |
| `src/modules/commands/services/` | 协调补全、键盘、焦点、执行结果、会话身份与输入版本 |
| `src/modules/commands/ui/` | 使用共享 Surface、ListItem、StatusText 的面板 |
| `src/modules/commands/public/` | 模块声明、输入协调器与解析器的公开入口 |
| `src/modules/commands/module.ts` | 注册帮助指令；帮助内容读取当前已注册指令 |
| `src/modules/chat/services/commands.ts` | 聊天拥有的模型、强度和压缩指令定义 |
| `src/modules/chat/services/runtime-selection.js` | 原按钮与指令共同使用的模型／强度状态操作 |
| `src/resources/styles/commands.css` | 指令面板和本次轻量可读性、空状态样式 |

装配在 `FrontendContributions.commands` 创建有拥有者的注册表；commands 模块注册帮助，chat 模块注册业务指令。指令模块通过注入的 CommandContext 调用业务操作，不读取 App 或其他模块的私有实现。

执行结果明确区分 `success`、`select`、`help`、`unavailable`、`error`。运行时选项闭包保留供应商 ID 与模型值，执行时再次检查有效性；不使用显示名称作为唯一标识。所有补全面板和监听器随控制器生命周期清理；卸载时取消未完成的压缩请求，遗留的进行中通知显示“已中断”，不误报完成。

这是源码扩展机制，本版不提供用户自定义指令、宏、多指令执行、运行时安装插件或 Agent 权限。

## 轻量界面变更

空状态按服务检查／离线、未配置模型、可聊天展示对应引导。离线不误报为模型配置问题，尚不可聊天时隐藏推荐问题。窄屏缩小欢迎标题和留白。

提高输入区帮助文字和空状态辅助信息的可读性；侧栏隐藏重复的“查找聊天”可见标签，保留其无障碍文字、原搜索按钮、输入框及快捷键。按钮外观和位置不做重新设计。

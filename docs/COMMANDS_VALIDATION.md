## 新增覆盖

- 指令名称、中文用途搜索、中文强度、合法／非法参数、特殊水平空白、Unicode 换行、普通正文、代码块与 `//` 字面量。
- 只有唯一精确模型名能直接执行；重名选择供应商；部分匹配不自动切换；禁用模型隐藏；执行时复查模型有效性。
- 原按钮与指令共用模型／强度操作，保留最近选择记忆和恢复继承行为。
- 上下方向键、Tab 仅补全、Enter 确认、Esc、输入法候选、帮助页键盘滚动与焦点恢复。
- 首次补全 `/compact` 不触发请求；重复压缩、空历史、失败和错误参数保留输入。
- 指令不写入普通聊天记录、标题和请求消息；附件保留；异步结果不覆盖新输入和另一会话草稿。
- 即使用户先改写输入再输入相同内容，或离开再回到原会话，旧异步回调也不能清除新草稿。
- 生成期间可提前选择下次请求的模型与强度；实际点击停止按钮只停止回复，不执行输入中的指令。
- 自动压缩等待期间通过原按钮切换模型，压缩及随后发送仍使用原请求快照。
- 指令协调器销毁后移除面板和监听器，忽略晚到结果。未完成压缩被取消，遗留进行中通知不误报成功。
- 服务离线、未配置模型、可以聊天三种空状态；响应式面板、表面 hover 及默认浅深主题文字对比度。

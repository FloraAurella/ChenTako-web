# 本轮前端完成计划（Agent 与后端除外）

本计划承接已完成的模块化和指令系统，按用户 2026-09-12 最新要求完成前端；用户将另行下达后端修改指令。

## 必须完成

1. 本地 Git 基线提交及分阶段提交；明确、可执行的 AGENTS.md 模块化约束。
2. 项目知识库独立模块：上传 UTF-8 文本／Markdown／代码、文件列表、全文预览、替换／删除、项目隔离、刷新恢复和备份恢复。
3. 每次请求完整携带项目资料；与历史压缩严格隔离；快照一致；预算超限或资料缺失阻止发送并提供可处理错误。
4. 聊天中明确当前项目与资料状态，提供知识库入口；项目管理与历史导航在各宽度可用。
5. 预算明细区分指令／系统提示词、固定项目资料、历史与摘要、本次输入／附件、输出预留。估算不是实际供应商精确计费。
6. 设置页区分常用与高级配置、明确全局默认和项目继承／覆盖关系；不删除工具、技能或数据管理。
7. 统一共享模板与令牌，保留用户要求暂不变动的现有按钮；键盘、空状态、错误状态与响应式验证。
8. 完成前端所需指令入口，复用已有导入导出流程，不实现自定义指令、宏或 Agent 功能。
9. 排查历史测试基线：修复真实前端问题，对已失效的断言说明依据后修正；不以历史失败标签掩盖当前未验证行为。
10. 安装／构建配置、文档与测试能够从当前仓库独立复现，不依赖原 Clawbox 源码路径。

## 不在本轮实施

Node 后端、Electron 主进程、IPC／SQLite／服务部署、真实供应商凭据与 Agent 权限／执行系统。前端沿用已有 HTTP 协议；通过兼容的系统提示词组合完成全文注入，后端不在本轮改动。

## 验收证据

逐项记录到后续前端验证文档：源码边界、自动化测试、模拟请求内容、资料持久化与降级场景、浅深主题及桌面／平板／手机截图、Git 提交。完成状态必须逐项由实际结果支持。

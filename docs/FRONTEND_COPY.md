## 展示规则

- 标题能说明用途时，不再追加同义介绍；不重复分组、卡片和字段的含义。
- 必要提示就近用一句话说明，避免操作教程和实现细节常驻。
- 空状态只给下一步，不重复展示无数据列表与无数据预览。
- 文件格式、限额、费用相关行为、不可用能力、保存失败与删除后果仍需明确说明。
- 用户的会话、项目名、文件正文、系统提示词、工具描述和技能内容不得自动精简。
- 更新记录保留原文，在关于页按需展开；简短按钮标签与无障碍名称继续保留。

### 真实产品缺陷（本轮代码级修复，来自快照审核）

**1. 打开会话不回底，长对话末条消息 meta 被裁剪**：`.message-entry` 使用 `content-visibility: auto` 估高，会话打开后单帧 `scrollToBottom` 执行时列表 `scrollHeight == clientHeight`（估高未展开），滚动落空且不再补滚；内容随后增高，用户停留在列表顶部。影响工具时间线、产物工具栏、图片等待态等所有内容超屏场景。修复：chat 控制器新增 `settleFollowToBottom()`——等待消息列表提交首个内容帧后，连续数帧钉底直到高度稳定且贴底（上限 60 帧）；用户上滚（解除跟随）立即让位。经 DOM 探针验证：修复前 scrollTop=0、meta 被滚动容器裁剪；修复后 scrollTop=85、meta 完整可见。

**2. 空会话回底pinning非确定 + 居中内容超高时顶部不可达**：初版 settle 循环在空会话的瞬态布局上偶发把空状态卡片钉到"标题被裁剪"的滚动位置（不同运行快照二值不同），且 `.empty-stage` 的 flex 居中在内容超高（720 高度视口）时把卡片顶部裁剪为不可达区域——经典"居中溢出"缺陷。修复：settle 循环对空会话整体跳过（无可回底内容，保持顶部），并等待列表提交内容帧后再判定，消除时序歧义；`.empty-card` 改用 `margin: auto` 安全居中，内容超高时退化为顶部对齐、完整可滚动。修复后空会话截图跨运行逐字节一致。

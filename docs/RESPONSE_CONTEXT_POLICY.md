# 响应结束后的压缩与一次性标题

2026-09-13 起，自动压缩在一次正常模型响应结束、完整回答写入会话后检查阈值。发送前仅校验上下文预算与资料完整性，不再自动压缩。

## 使用方式

在“设置 → 上下文与提示词 → 上下文策略”配置三项：

- **压缩触发阈值**：默认 80%，可选 10%–95%。达到阈值（含等号）即触发一次压缩。
- **压缩模型**：用于自动压缩与圆环、`/compact` 手动压缩，可选指定供应商下的模型或“与当前对话模型相同”。
- **标题模型**：首次发送时与回答并行生成标题，可独立选择，也可跟随对话模型。

所有项目继承聊天默认值，也可逐项自定义。设置自动保存，未保存或存储失败会就近提示。输入预算始终自动计算：`floor(对话模型窗口 × 0.95) − 最大输出`。专用模型的窗口不改变对话的触发阈值。

## 压缩规则

判断使用完整回答结束后的上下文估算，不包含下一条草稿。圆环和触发判断共用实际请求消息投影，不将消息 ID、时间、状态或内部思考作为正文预算重复计算。系统提示词、项目固定资料、历史与摘要、本次输入/附件和输出预留继续分别展示。

正式请求开始准备时，固定对话模型、配置、项目资料及两个辅助模型的供应商身份和额度快照。自动压缩使用同一快照。压缩请求仅包含已完成历史和已有有效摘要，不包含项目资料或人格提示词；下一次正式请求仍完整携带该次准备时捕获的项目资料。

每次正常响应最多自动压缩一次，不循环追求低于阈值。手动停止、报错或未完成的响应不自动压缩。压缩期间不能发送新消息，但可编辑下一条草稿、切换查看其他对话。压缩失败保留原历史，不自动重试；没有可压缩历史时不请求模型。

专用模型被删除/禁用、模型不存在、窗口不足或不支持完整历史附件时明确失败，不隐式切换模型或静默遗漏资料。压缩期间的历史或分支变化会使结果失效；会话删除与模块释放会取消辅助请求，过期结果不得写回。

发送前超预算时保留草稿与附件，提示手动压缩、精简输入或选择更大窗口模型。固定资料与本次输入已超预算时，不能通过历史压缩解决，不截断或忽略文件。

## 标题与首次响应锁定

第一条消息通过校验、正式进入会话时，记录 `titleGenerationAttempted`，并开始标题请求。仅使用首次输入文字；纯附件输入使用文件名，不把附件全文、项目资料、后续消息或指令发送给标题模型。等待时使用输入截取标题；成功替换为简短单行标题，遵守现有长度限制；失败保留备用标题且不自动重试。

新对话的首次响应运行期间不可改名、删除、置顶、移动项目、更换会话模型/强度，或编辑、删除、复制分支消息。对应按钮/菜单/指令及领域入口均检查锁定。含有首次响应中会话的项目不能删除，因为删除会间接移动该会话。允许停止、切换查看和编辑下一条草稿。

首次响应正常完成、失败或停止均解除锁定。标题请求较慢不延长锁定，也不阻塞下一次发送；用户手动改名后，迟到的自动标题不能覆盖。后续回答继续使用既有操作规则。

运行锁与标题修改版本不进入持久化/归档；刷新导致请求中断后可正常修改。一次性标记随会话保存并支持归档；旧的非空会话视为已使用机会，副本与分支继承标题且不再次生成。清空旧会话的消息也不会恢复机会。

## 接口与模块边界

`POST /api/chat/title` 接收 `{ provider: { id, displayName, baseUrl, responseFormat }, model, input }`，成功返回 `{ ok: true, title }`。线上契约为 `src/contracts/auxiliary.ts` 与 `server/contracts/auxiliary.ts`；路由常量有一致性测试。

标题路由与既有 `/api/chat/compress` 共用后端聊天模块的辅助请求生命周期，复用注册表匹配、SSRF/密钥校验、超时、断连取消与四协议适配。仅使用固定技术指令，不执行扩展。`/api/chat/compress` 请求/返回结构保持兼容；正式 `/api/chat` 仍发送兼容的 `chatConfig.version: 1` 与 `inputBudget: null`。

聊天模块拥有首次响应规则、标题服务与辅助模型快照；上下文模块拥有配置、预算和阈值规则；项目状态的修改权限由 App 注入聊天公共规则。会话数据仍仅保存在前端。后端 SQLite 仍只存供应商与加密 API Key。

设置 schema 升级为 2。旧 `inputBudget` / `autoCompress` 停止生效，默认值和项目覆盖的旧值保存在 `legacySettingsBackup.contextPolicy` 白名单备份中；阈值和其他有效设置保留。新增模型字段默认 `null`（跟随对话模型）。

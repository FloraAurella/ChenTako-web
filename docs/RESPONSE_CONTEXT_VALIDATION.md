## 验证行为

- 响应正常结束后触发压缩；流式/非流式行为一致；发送前没有自动压缩调用。阈值以下不触发、等于和超过触发；停止、错误、未结束均不触发。
- 最新回答进入压缩输入，下一条草稿不进入；压缩期间允许编辑但禁止发送。失败保留消息/草稿且不循环重试。
- 持续滚动期间响应收尾与自动压缩及时执行；切换查看后结果只写回原会话。长 Markdown/代码的合帧、持久化与阅读位置回归通过。
- 压缩与标题采用专用模型，选择失效不回退。标题四协议通过本地模拟上游验证；空输入、扩展执行、窗口不足、空输出返回明确错误。压缩模型跳过历史附件时拒绝生成不完整摘要。
- 首次并行生成标题且每个会话只尝试一次；失败回退；第二次发送、刷新和复制分支均不重发。纯附件使用名称。晚到标题不覆盖手动改名，标题未完成也不阻塞后续发送。
- 首次响应锁定菜单、模型/强度指令、消息修改、项目移动与删除；正常/停止/错误均解锁。领域入口再次校验，运行锁不进入持久化/归档。后续响应维持既有修改行为。
- 配置 schema 2 迁移、阈值保留、旧预算/开关白名单备份、模型项目覆盖/继承、自动保存与存储失败回归通过。一次性标记支持旧记录、刷新和导入导出。
- 项目资料每次正式请求全文携带、与摘要请求隔离；固定资料过量或缺失时阻止发送，草稿和附件保留。上传失败、异步卸载与存储失败原有测试继续通过。
- 圆环和压缩触发共用实际请求消息投影；用户可分别解释系统/资料/历史与摘要/草稿/输出预留。原始消息 ID、时间和内部思考不会重复影响请求用量。
- 默认浅深主题的 1280、1024、390 宽度无页面级横向溢出；中文输入法、键盘指令、继承禁用和错误状态通过。模型选择器复用新增共享 `SelectField`，没有新增页面专用样式。

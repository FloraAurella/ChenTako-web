# 设置即时保存与供应商双列工作区

依据 2026-09-13 用户请求及随后确认的层级划分。

## 使用

- 供应商名称、API 地址、协议、聊天开关和上下文/提示词一级页面自动保存。选择和开关立即提交，连续文本输入停顿约 320ms 后提交；离开字段或切换页面提前排空队列。中文输入法组合期间不提交中间拼音。
- 一级页面显示已保存、等待保存或保存中，没有保存/放弃按钮。格式无效、接口失败或本地存储失败时保留输入并显示原因；可修正输入，或点击错误旁的重试。未提交的错误输入阻止直接导航丢失。
- 二级模型编辑和模型默认值弹窗保留保存更改。取消不应用参数；保存直接写入供应商配置，无需回一级再次保存。默认模型与删除入口放在弹窗中，模型行仅显示名称、能力、上下文徽标、测试及编辑。
- 空模型列表可以保存；新建供应商名称和 URL 完整后自动注册。未完成的新建配置可以从标题栏取消。删除仍需确认，已有聊天不随配置删除而删除。
- 桌面和平板左右两列各自滚动，滚到底不带动另一列或整个设置内容。手机显示当前列表或详情，标题栏返回按钮可回到供应商列表。
- 外观、上下文、工具、技能、数据、关于与供应商共用 1100px 最大宽度，左右留白一致；手机采用自适应宽度。

## 目录与职责

- src/modules/connections/services/provider-service.ts：供应商保存队列、草稿基线、模型二级提交与错误恢复。
- src/modules/context/services/context-service.ts：聊天默认/项目覆盖的自动保存、本地写入失败回滚。
- src/modules/connections/ui/provider-workspace.tsx、provider-dialogs.tsx：紧凑卡片、一级状态、二级弹窗。
- src/resources/styles/settings.css、responsive.css：统一宽度与独立滚动；复用共享按钮、输入、Surface 和图标资源。
- test/provider-autosave.test.ts、test/context-service.test.ts：串行写入、迟到响应、IME、失败重试、项目隔离、二级保存与空列表。
- e2e/settings-autosave.spec.js、e2e/providers-compact.spec.js：滚轮隔离、卡片坐标、一级刷新恢复、二级保存/取消、手机列表返回。

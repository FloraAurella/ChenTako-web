# ChenTako 双态 SVG 背景画作

2026-09-13，用户要求两套精细 SVG 背景，并确认「精细克制，主要装饰边缘」。

## 设计

- 浅色：日轮、细刻度光线、金色气流、竹签、竹盘章鱼烧，包含酱汁、蛋黄酱、海苔和木鱼花细节；左下角竹叶补充构图。
- 深色：独立绘制的两盏灯笼、细骨架、穗线、烟气与余烬，以及右下角的弧形纹路；不只是把浅色画作反色。
- 画作 1600×1000、透明底，中央留白。桌面额外用遮罩保护开放式正文，手机进一步淡化并限制在右缘。窄屏允许装饰裁切，不要求完整显示整幅作品。
- 无动画、计时器和额外交互；不会捕获点击、焦点或滚动，不增加设置选项。

## 源码与接入

`src/resources/artworks/tako-daylight.svg`（6224 字节）与 `tako-nightfall.svg`（3268 字节），合计 9492 字节。只包含本地矢量、渐变和绘制几何，不含脚本、外链、嵌入图片或用户内容。

`src/resources/artworks/index.js` 经系统资源注册表提供 URL。Vite 以独立 SVG 资产输出，不将小图内联为 data URI。appearance 控制器随主题与 scheme 更新 `--theme-artwork`，非该主题回退 none，Scope 释放清理。布局样式使用 `.app-canvas::before` 装饰层，主体仍在 `.app-shell` 上层，保持卡片材质与透景行为。

旧历史主题 ID `everforest` 继续作为当前主题的兼容标识。未修改用户导入 SVG 安全规则、旧档案、聊天数据或后端。本次背景应用于主应用聊天及设置画布；独立首次启动页没有该画布，保持原样。

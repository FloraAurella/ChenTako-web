# 写入工作区（2026-09-13 更新）

## ChenTako-web 当前运行范围（2026-09-13）

此副本暂时只启用普通聊天。writing 模块在应用装配时停用：不显示章节工作区、右侧栏按钮及写作模式状态，不注册 /create、/name、/write、/edit、/chat 和 @ 章节选择指令。/model、/effort、/compact、/help 保留。旧指令会报错并保留输入，不自动当作普通消息发送。

只有 prompts/system.json（聊天）、summary.json（历史摘要）、title.json（自动标题）生效，启动和构建时的自动转换也仅处理这三个文件。discussion.json、write.json、edit.json、continuity.json 保留原文件但不导入、不转换、不用于请求。已有作品数据及兼容代码保留，停用不删除数据；旧对话保存的写作模式不影响当前普通聊天，也不自动携带章节正文。

该状态仅适用于 ChenTako-web，原 ChenTako 副本未修改。下文写作功能说明保留作恢复功能时参考，不代表此副本当前启用。


本次用户要求取代首版候选稿与强制连贯性检查流程。一个对话是一部作品；聊天／剧情讨论显示在左侧，写作／编辑要求及正文显示在右侧工作区。页面右上角的「右边栏」图标控制工作区开合，不再提供工作区内或输入区的文字开关；展开后继续显示同一章节、版本和手动编辑内容；桌面收起状态随作品保存，手机在聊天和工作区间切换。

## 指令和模式

- `/create 章名`：创建并选中章节，不调用模型、不改变当前模式；工作区不提供创建表单。
- `/name 旧名字 新名字`：重命名已有章节，不改变章节 ID、正文、版本、选章或模式。含空格时使用双引号，例如 `/name "雨夜 重逢" "黎明 之后"`。缺少参数、重名、不存在的旧名字、生成锁或未保存的手动编辑会明确报错，不发送模型请求。
- `@章名` 或 `@"带空格的章名"`：选择章节，不改变模式。
- `/write`：直接进入持续写作模式，后续普通输入都是写作要求。
- `/edit`：直接进入持续编辑模式，后续普通输入修改当前章的当前正文版本。
- `/chat`：直接返回聊天／讨论，后续内容显示在左侧。
- `@第六章 /edit 修改对话`：选章、切换模式并提交要求。

菜单选中模式指令时立即执行，不再要求二次确认；单独切换模式不调用模型、不产生聊天消息，保留附件。模式不会在生成完成、失败、回档、选章、收起工作区或删除选中章节时自动重置。没有选章时仍保持写作／编辑模式，但内容请求会提示先创建或选择章节。

## 正文与回档

AI 返回文本实时写入右侧正文，完成后自动保存，取消候选稿和采纳按钮。每次写入保留一个版本，显示要求、章节名、正文和 `当前序号 / 总数`。上一版／下一版切换当前正文，可从旧版本继续编辑形成新的版本；其他记录不删除。版本记录也提供直接恢复入口。

手动编辑点“保存正文”直接创建版本。未保存的手动编辑在切换对话时保存到原章节；生成期间锁定目标章内容和版本修改，但允许查看其他章节。停止或失败保留已收到的部分正文并标记未完整结束；首字前失败不清空原正文，同时留下失败版本记录。

旧版正式正文、候选稿和候选修订迁移到正文版本历史；最新非空候选成为当前正文，旧正式版本仍可恢复。迁移仅一次，不重复添加版本。原候选字段只作为兼容读取结构保留，不再用于当前界面和生成流程。

## 格式与上下文

写作和编辑按原样保存模型文本，不要求 JSON、特定标题或 Markdown 包裹，也不通过严格 JSON 检查作为写入前置条件。自动连贯性检查已取消；`prompts/continuity.json` 保留作者文件，但当前直接写入流程不调用它。每次内容请求通常只有一次正文模型调用（独立的首次标题／历史压缩按已有策略可能另发请求）。

提示词仍仅由根目录 `prompts/` 决定；本次未改写作者文案。模型若遵循提示词输出说明或代码围栏，正文也会原样保存，可手动修改。预算、文件完整读取和传输上限继续检查，不通过截断正文解决超限。

讨论、写作和编辑都携带本作品全部当前章节正文及项目资料全文；版本回档后下一次请求使用回档后的正文。未选中的历史版本不默认发送。正文不进入历史摘要；隐藏在聊天数据中的写作请求提供上下文顺序，写作回复使用短回执参与历史，完整内容通过作品固定上下文携带。

## 保存和迁移

作品仍使用前端存储，随 ZIP 会话归档与独立作品 JSON 备份导出／导入。新增 `workspaceVersion: 2`、`collapsed`、`currentVersionId` 和版本要求字段。消息 `outputSurface: workspace` 标记左右归属，刷新后保留；此标记不参与模型传输。

旧作品无新增标记时自动迁移，未来不支持版本明确报错并保留原数据供导出。旧应用不理解新工作区布局和版本选择，完整往返需使用支持 workspaceVersion 2 的版本。存储失败保留内存内容、显示未保存并支持导出；不要在未保存状态下刷新。

## 模块边界

writing 拥有正文版本服务、模式、指令贡献、面板及请求结果归属。通用指令契约 `executeOnSelect` 支持贡献声明直接执行；通用请求契约 `outputSurface` 支持工作区输出，chat 只负责请求传输、持久消息标记及聊天渲染分流。未实现 Agent Loop、分支关系图或富文本编辑器。

右侧栏使用与左侧栏一致的 240ms 动效令牌，沿右边缘滑入／滑出，反复点击会从当前位置反向过渡。系统减少动态效果时取消位移。收起面板标记为 inert，不能被键盘或辅助技术误访问。手机通过同一图标返回聊天。
